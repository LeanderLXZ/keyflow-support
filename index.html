Get started

  1. Allow Accessibility access. Open System Settings → Privacy & Security → Accessibility and enable Keyflow. If it is missing, click + and select your installed Keyflow app.
  2. Choose a destination. Open the app you want to type into and click its text field.
  3. Compose in Keyflow. Type or paste a short sample into the editor.
  4. Send your text. Click the Send button.
  5. Check the result. Confirm that the destination received the text you intended.

Keyflow relays text you provide. It does not include speech recognition or a transcription service.

Quick answers

When something interrupts your flow.

Nothing arrives in the destination app.

Check that Keyflow is enabled in System Settings → Privacy & Security → Accessibility. Click a writable field in your destination app and check that Allowed Target includes that app. Keyflow’s status line can explain why sending is unavailable. Secure Input and some remote-session configurations can prevent simulated input.

Characters are missing or look different.

Try a longer character delay and a different Sending Mode with harmless sample text. Check both your local keyboard layout and any remote input method. Automatic mode chooses Standard for ASCII text and Unicode otherwise. Compatibility depends on the destination; completion means events were posted, not that every character was accepted.

A line break submits my message.

Check Send Return As in Typing settings. The default is Shift + Return. Different destinations handle Return differently, so use a safe sample before sending important text.

How do I stop a send?

Click Stop. Sending also stops when the destination or permission changes, preserving the original editor text. Some characters may already have arrived; check the destination before retrying to avoid duplicates.

What does Private Mode keep private?

Private Mode skips new History entries. Draft recovery still saves editor text locally, including in Private Mode. Existing History and Favorites remain, and the destination app follows its own storage practices. Read the privacy policy for details.

Does my draft survive quitting?

Draft recovery is intended for an unexpected exit. Normal Quit attempts to clear the draft. Save text you need before deliberately quitting. If Keyflow reports a storage failure, do not assume the draft is recoverable.

Where is my data, and how can I remove it?

Settings → Data shows the folder used by your installed version. Clear History and Clear Favorites are separate actions; clearing one keeps the other. Reset Settings preserves your data. The privacy policy explains local storage, backups, and deletion.

Why is Keyflow still running after I close its window?

When Keep in Menu Bar is enabled, closing the main window can leave Keyflow running. Use Quit to end the application.

Get in touch

Still need a hand?

Questions, bug reports, and feature ideas are welcome.

keyflowapp.support@gmail.com

A useful bug report includes

  • Keyflow version/build, macOS version, and Mac processor.
  • Destination app and whether you use a remote session.
  • Sending Mode, character delay, and line-break setting.
  • Steps to reproduce with fictional sample text.

Please leave out passwords, confidential text, full History databases, and unredacted logs. A cropped, redacted screenshot is welcome if it helps.
